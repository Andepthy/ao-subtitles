# ao-subtitles

This is an archive of some self-made subtitles for [About Oliver](https://www.youtube.com/@AboutOliver)'s game VODs.

## File naming

| File | Description |
| --- | --- |
| `NN.srt` | English subtitles transcribed with tools such as `faster-whisper` |
| `NN-zh.srt` | Chinese subtitles translated from the English subtitles above |
| `NN-zh-outdated.srt` | Older Chinese subtitles, translated from YouTube auto-captions; timing and wording are inaccurate |
| `info.txt` | Contains useful information about the corresponding playlist videos |

`NN` is the episode number.

## Disclaimer

The Chinese subtitles were produced with **LLM translation**, and only some of them were lightly proofread by hand; **neither translation accuracy nor timing is guaranteed**.

The subtitles are derivative works of the original videos, whose rights belong to About Oliver. Please do not use them for commercial purposes; if a rights holder does not want this content to be public, contact me and it will be removed.
